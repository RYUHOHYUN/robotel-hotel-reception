# YOLO 캔 검출 학습·평가

## 목표

호텔 웰컴 드링크 캔 4종을 구분하는 객체 검출 모델을 실험했습니다.

```text
coffee / cola / tea / sikhye
```

## 데이터 구성

- 캔의 위치 변화
- 정면·기울어진 각도 변화
- 배치 순서 변화
- 거리와 배경 변화
- 학습·평가 이미지의 라벨 상태 확인

## 평가 방식

- YOLOv8/YOLO11 계열 모델 결과 비교
- mAP, Precision, Recall, F1 확인
- 실제 예측 이미지에서 오검출과 누락 확인

## 핵심 경험

수치가 좋아도 실제 배치에서 성능이 다를 수 있었습니다. 단순히 이미지 수를 늘리는 것보다 실제 사용 환경과 비슷한 **위치·각도·순서·배경의 다양성**을 확보하는 것이 더 중요했습니다.

> 학습 데이터와 모델 파일은 용량과 개인정보·라이선스 문제로 이 저장소에 포함하지 않았습니다.
