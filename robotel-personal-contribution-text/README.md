# ROBOTEL — 개인 구현 정리

호텔 리셉션 자동화 프로젝트에서 제가 직접 구현·실험·검증한 내용을 간략하게 정리한 저장소입니다.

이 저장소는 전체 팀 프로젝트가 아니라 **좌표 기반 로봇 제어, YOLO 캔 검출, 얼굴 확인, 경품 등수 OCR**과 관련된 개인 기여 내용을 중심으로 구성했습니다.

## 한눈에 보기

### 1. 좌표 기반 로봇 제어

카드키와 3등 상품 키링을 옮기기 위한 Pick & Place 동작을 구현했습니다.

- 사용 장비: Doosan M0609, OnRobot RG2
- 주요 값: `posx`, `posj`, `width`, `force`
- 핵심 구현: 물체별 좌표와 상단 접근점, 들어올림 지점, 배치 지점을 분리
- 이동 순서: 초기 위치 → 상단 접근 → Pick → Lift → Place 상단 → Place 하단 → 초기 위치

### 2. YOLO 캔 검출

호텔 웰컴 드링크 캔 4종을 구분하기 위한 데이터셋을 구성하고 모델을 비교했습니다.

- 클래스: `coffee`, `cola`, `tea`, `sikhye`
- 데이터 구성: 위치, 각도, 순서, 거리, 배경 변화 포함
- 평가 항목: mAP, Precision, Recall, F1
- 확인 방법: 수치 지표와 실제 예측 이미지를 함께 비교

### 3. 얼굴 확인과 경품 등수 OCR

여권 사진과 실시간 얼굴을 비교하고, 종이 경품의 등수를 읽는 기능을 구현했습니다.

- 얼굴 검출: YuNet
- 얼굴 비교: SFace 특징 벡터
- 판정 안정화: 여러 프레임의 비교 점수 사용
- 실제 얼굴 확인 보조: RealSense Depth
- 경품 등수 인식: PaddleOCR 한국어 모델
- OCR 안정화: 좁은 ROI, 전처리 비교, 선명한 프레임 선택, 신뢰도 가중 투표

## 파일 구성

- `robot_control/card_move_node.py`: 카드키 좌표 이동
- `robot_control/keyring_move_node.py`: 3등 상품 키링 좌표 이동
- `robot_control/onrobot_card.py`: 카드키 이동용 RG2 제어
- `robot_control/onrobot_rg2.py`: 키링 이동용 RG2 제어
- `vision/face_verification_node.py`: YuNet, SFace, Depth 기반 얼굴 확인
- `vision/rank_ocr_node.py`: PaddleOCR 기반 경품 등수 인식
- `yolo/README.md`: 캔 검출 데이터 구성과 평가 경험

## 문제 해결 경험

### 좌표는 맞지만 주변 구조물과 충돌하는 문제

목표 좌표로 바로 이동하지 않고 상단 접근점과 들어올림 지점을 따로 구성했습니다. 물체 주변 환경을 고정한 뒤 `Pick → Lift → Place 상단 → Place 하단` 순서로 이동해 충돌 가능성을 줄였습니다.

### 카드키와 키링이 미끄러지거나 걸리는 문제

물체마다 두께와 접촉면이 달라 같은 설정을 사용할 수 없었습니다. 각 물체의 좌표, 접근 높이, 그리퍼 `width`, `force`를 하나의 세트로 조정했습니다.

### YOLO 지표와 실제 화면 성능이 다른 문제

단순히 이미지 수만 늘리지 않고 실제 배치와 비슷한 위치, 각도, 순서, 거리, 배경 변화를 데이터에 포함했습니다. 평가 지표와 실제 예측 화면을 함께 확인했습니다.

### 얼굴과 문자 인식에 학습 비용이 커지는 문제

모든 문제를 YOLO로 학습하지 않고, 얼굴에는 YuNet과 SFace를 사용하고 문자 판독에는 PaddleOCR를 적용했습니다. 이미 검증된 전용 모델을 활용해 구현 시간을 줄였습니다.

## 실행 전 주의사항

- 로봇 좌표와 그리퍼 값은 프로젝트 작업대와 물체 배치를 기준으로 티칭한 값입니다.
- 실제 로봇에서는 저속 실행, Dry Run, 충돌 영역 확인 후 사용해야 합니다.
- 비전 코드는 ROS 2 인터페이스, 카메라 토픽, 얼굴 모델 파일이 추가로 필요합니다.
- 기준 환경은 Ubuntu 22.04, ROS 2 Humble, Doosan M0609, OnRobot RG2입니다.
